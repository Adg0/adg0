### Engineering Philosophy

```text
LOCAL-FIRST · ZERO TELEMETRY · USER SOVEREIGNTY
```

- **Data Sovereignty:** Personal habit, biometric, and reading data remain exclusively on the user's device in human-readable formats (plaintext Markdown, local JSON/SQLite).
- **Zero Telemetry:** Software operates with zero analytics trackers, third-party cookies, or silent background pings.
- **Offline Reliability:** Core utilities must remain fully operational without requiring remote cloud services or network permissions.
